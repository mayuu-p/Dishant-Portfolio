A restricted GitHub token lets this dashboard save media and updates directly into the Dishant-Portfolio repository. The token stays only in this open browser tab and is never written to a file or database.

Create restricted token ↗
Create a Fine-grained token → select only mayuu-p / Dishant-Portfolio → Repository permissions → Contents: Read and write. No other permissions. Set an expiry. Never paste this token into public code or share it.
